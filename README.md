# agrovet-sales-d# Agrovet Sales Dashboard

An interactive sales dashboard for a multi-branch agrovet business in Kenya. It turns point-of-sale (POS) data into KPIs and charts that update when you pick a branch.

**Live demo:** https://davidmaumo18-dot.github.io/agrovet-sales-dashboard/

## What it shows

- **KPI cards:** revenue, profit, margin and units sold
- **Revenue and profit by month:** a line chart for spotting trends and seasonality
- **Revenue by product:** the top 8 products ranked by sales
- **Share of revenue:** each top product's slice of total sales
- **Branch filter:** Athi River, Machakos Town and Matuu. Every card and chart updates when you click a branch.

## Tools used

- **Python (pandas):** data cleaning and aggregation
- **JavaScript and Chart.js:** interactive charts
- **HTML and CSS:** layout and styling

## How the data was prepared

Source file: the agrovet animal feed POS dataset (`agrovet_animal_feed_pos_dataset.csv`).

1. Kept **completed orders only**, so cancelled or pending orders don't inflate sales.
2. Used **net sales** (after discount) as revenue and **cost of goods** as cost.
3. Grouped the transactions by month, product and branch to keep the dashboard fast.
4. Saved the result as `data.js`, which the dashboard reads.

## Project files

- `index.html`: the dashboard page, with its layout, styling and chart code
- `data.js`: the prepared data (generated by the Python script)
- `prepare_data.py`: the data preparation script (add it to the repository if you want others to reproduce the data)

## Run it yourself

1. Download the repository.
2. Open `index.html` in any browser. No installation is needed.
3. To use your own data, run `python prepare_data.py` with your CSV in the same folder. It regenerates `data.js`.

## Key findings

- Peter is the top salesperson at about KES 2.08M, roughly a quarter of all revenue and about 2.5 times Brian's KES 818,160.
- Bank transfer and M-PESA lead the payment methods, ahead of cash and card.
- Dairy meal 70kg is the top product, followed by Poultry Starter Feed 50kg.
- The overall margin is 18.9%.
